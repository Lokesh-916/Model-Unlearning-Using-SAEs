# E3: detect here, erase there (causal localisation, DEV only)

Lab PC (labpc, RTX 2000 Ada), gemma-2-2b-it, DEV split only (never TEST). Branch `exp/E3-causal-localisation` d3cd127; queue jobs E3-rank, E3-000..012, E3-summary (2026-11-10, item-level resume on). Exploratory, not a claim input. Ids and metrics only.

**Method.** Per SAE (Gemma Scope 2B residual 16k, canonical L0 at layers 3-14, plus DSG's own layer-3 SAE l0_142): features ranked by attribution patching (activation x gradient of the correct-answer logit margin, summed over positions > 0, SAE error detached and added back) on the even-indexed half of WMDP-Bio dev (n 319). Validation: true zero-ablation (features set to 0 at every position but BOS, SAE error added back) on every input (forced-on) of the top 10 / 20 / 50. Controls: DSG's 20 detection features zero-ablated, 50 random features that fire on the ranking items, DSG's -500 clamp forced-on (tau -1). Forget = WMDP-Bio dev **held-out half** (n 318, never used for ranking; all-dev column also given); utility = MMLU dev, full MMLU minus the 9 bio-adjacent subjects (n 6075); benign biology = A3's five subjects, dev (n 428). 95 % bootstrap CIs; Δ vs base paired on the same items (paired bootstrap, exact McNemar). Batch size 8 for every run (dev).
