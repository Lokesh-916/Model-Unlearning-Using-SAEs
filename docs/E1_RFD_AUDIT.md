# E1 three-number audit (R, F, a/u decomposition)

Generated by `python -m dsgx.analysis.rfd_audit` (CPU, existing X1 TEST per-item logs, no model runs). Each machine is its own table; numbers are never mixed across machines. Pooled over the seeds listed; 95 % item-cluster bootstrap CIs (2000 resamples, items resampled with all their seed rows); n = items × seeds.

Definitions: R (forget) / F (benign) = gate fire rate; a_fire / u_fire = gated-run accuracy on fired rows; a_miss / u_base = **base-model** accuracy (X1 base run, same item ids and attack) on the rows the gate did not fire on. pred = (1 − R)·a_miss + R·a_fire (utility: (1 − F)·u_base + F·u_fire). In-CI = pred inside the observed accuracy's 95 % CI. With a_miss taken from the gated run itself the formula is an identity; its largest |pred − obs| over all rows is given per machine as an arithmetic check. 'misses only' = (1 − R)·a_miss + R·0.25 (fired items at chance).
